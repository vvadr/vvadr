## 🚀 Featured AI Projects

### 🤖 Multi-Agent AI Analyst

AI-powered document analysis system combining **RAG, vector search, and multi-agent workflows**.

* Supports PDF, DOCX, and TXT documents
* Document parsing and intelligent chunking
* Embedding generation and vector retrieval
* Source-grounded question answering
* Multi-agent workflow orchestration
* RAG evaluation and observability
* Containerized AI backend

**Stack:** Python · FastAPI · Qdrant · LangGraph · Gemini · RAG · Docker

[Live Demo](https://multi-agent-ai-analyst-psi.vercel.app/)

---

### 📄 LoanSource AI

Source-grounded document intelligence system designed to generate answers based only on available evidence.

* Retrieval-Augmented Generation
* Semantic document search
* Page-level source citations
* Grounding verification
* Evidence-based answering
* Refusal when sufficient context is unavailable

**Focus:** RAG · LLMs · Retrieval · AI Reliability
